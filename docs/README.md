## Milestone Plans & Specs

The `superpowers/` folder contains historical milestone artifacts:

- **`superpowers/plans/`** — Implementation plans for each milestone (YYYY-MM-DD-name.md)
- **`superpowers/specs/`** — Design documents for each milestone (YYYY-MM-DD-name.md)

These are preserved for traceability. For current project status, see `AGENTS.md`.
