# Milestone Plans & Specs

This folder contains historical implementation plans and design documents for each milestone.

## Conventions

- **Plans** (`plans/`) — Step-by-step implementation checklists
- **Specs** (`specs/`) — Design documents (architecture decisions, data models, API shapes)

## File Naming

Both folders use `YYYY-MM-DD-name.md` format (e.g., `2026-08-12-permission-management.md`).

## Current Status

For current project status and completed milestones, see `AGENTS.md`.
