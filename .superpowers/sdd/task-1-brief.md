# Task 1: Add superAdmins Table to Schema

**Files:**
- Modify: `backend/src/database/schema.ts` (add table definition in public schema section)
- Create: New migration folder in `backend/drizzle/` (generated by `drizzle-kit`)

**Context:** This is the first task in creating seed data. We need a `super_admins` table in the public schema for platform-level SuperAdmin accounts (parallel to `candidate_accounts`).

## Steps

### Step 1: Add table definition to schema.ts

Insert after the `refreshTokens` table (after line 68) and before the "Tenant Schema Tables" comment:

```typescript
export const superAdmins = pgTable('super_admins', {
  id: uuid('id').defaultRandom().primaryKey(),
  email: varchar('email', { length: 255 }).notNull().unique(),
  passwordHash: varchar('password_hash', { length: 255 }).notNull(),
  name: varchar('name', { length: 100 }),
  createdAt: timestamp('created_at').defaultNow().notNull(),
});
```

### Step 2: Run typecheck

`cd backend && npm run typecheck` — must pass with no errors.

### Step 3: Generate migration

`cd backend && npx drizzle-kit generate` — should create a new migration folder in `backend/drizzle/` with `migration.sql` containing `CREATE TABLE "super_admins"`.

### Step 4: Commit

```
git add backend/src/database/schema.ts backend/drizzle/
git commit -m "feat(db): add super_admins table for platform-level admin accounts"
```
